# 💰 WealthFlow

> A clean and intuitive financial management dashboard designed to help users manage budgets, track finances, and make smarter investment decisions.

WealthFlow is a modern **personal finance and wealth management web application** focused on making financial planning simple, visual, and easy to understand.

## ✨ Features

* 📊 **Financial Dashboard** — Get a clear overview of your financial activity.
* 💸 **Budget Management** — Monitor income, expenses, and spending patterns.
* 📈 **Investment Planning** — Explore and manage investment-related information.
* 💡 **Smart Financial Insights** — Make better decisions using organized financial data.
* 📱 **Responsive UI** — Designed to work smoothly across different screen sizes.
* 🎨 **Modern Interface** — Clean dashboard built with reusable UI components.
* 🔐 **Supabase Integration** — Backend services and data management support.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AaryaBhanderi/WealthFlow-UI.git
cd WealthFlow-UI
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

### 4. Build for production

```bash
npm run build
```

## 🧪 Development

Run the linter with:

```bash
npm run lint
```

Preview the production build with:

```bash
npm run preview
```
